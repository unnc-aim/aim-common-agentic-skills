# Referee Skill - 零依赖版本

## 🎉 完全无需安装任何依赖！

这个版本使用纯 Python 标准库，基于关键词匹配进行检索，**无需安装 chromadb 或下载任何模型**。

## 快速开始

```bash

cd .claude/skills/referee
python3 query_simple.py "如何获取机器人血量"
python3 query_simple.py 0x0208
python3 query_simple.py --list
```

## 工作原理

1. **直接读取 chunks.json**（152KB，已预生成）
2. **关键词匹配** - 基于简单但有效的评分算法
3. **返回相关切片** - Claude Code 进行后处理和精准回答

### 评分策略

- 完整查询文本匹配：+10 分
- 关键词在内容中出现：每次 +2 分
- 关键词在元数据中出现：+5 分（命令码、描述、标题等）
- 命令码精确匹配：直接返回

## Claude Code 集成

当用户在 Claude Code 中提问时：

1. **我调用查询工具**：`python3 query_simple.py "用户问题"`
2. **工具返回相关切片**：包含命令码、数据格式、说明等
3. **我进行后处理**：
   - 理解用户真正想要什么
   - 从多个结果中提取关键信息
   - 简化和精准地回答
   - 提供使用示例和建议

### 示例对话

**用户:** 如何获取机器人的实时射击数据？

**我执行:** `python3 query_simple.py "实时射击数据"`

**工具返回:** 命令码 0x0207 的完整定义（弹丸类型、射速、初速度等）

**我回答:**
"要获取实时射击数据，使用命令码 **0x0207**。该命令在弹丸发射后立即发送，包含：

- **弹丸类型**（1 字节）：bit 1 表示 17mm，bit 2 表示 42mm
- **发射机构 ID**（1 字节）：1 为 17mm 发射机构，3 为 42mm 发射机构
- **弹丸射速**（1 字节）：单位 Hz
- **弹丸初速度**（4 字节）：单位 m/s

这是通过主控模块发送到对应机器人的常规链路数据。"

## 命令行选项

```bash

选项:
  --list              列出所有命令码
  --stats             显示知识库统计
  --json              以 JSON 格式输出
  -n, --num-results N 返回 N 个结果（默认 3）
```
